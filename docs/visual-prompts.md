# Visual assets

These assets illustrate repository stewardship. They do not represent a measured before/after outcome or an actual product interface.

| Asset | Production method |
| --- | --- |
| `assets/hero.png` | Built-in image generation, original output |
| `assets/before-after.png` | Built-in image generation, original output |
| `assets/workflow.svg` | Hand-authored, editable SVG |

The generated PNGs are copied unchanged into the repository. No private repository screenshots or experiment data are used.

## Hero prompt

```text
Use case: ads-marketing
Asset type: wide GitHub README hero illustration for an open-source AI coding skill named REPO STEWARD.
Primary request: Create a polished, original editorial 3D illustration that makes repository stewardship feel delightful and easy to understand.
Scene/backdrop: a deep midnight-blue gradient with subtle blueprint grid and a floating isometric research workspace.
Subject: a small friendly geometric assistant carrying a glowing folder, arranging a handful of luminous file cards into four clearly separated trays representing code, documentation, experiment inputs, and run outputs. Add a tiny abstract robot arm as a research cue, integrated into the workspace.
Style/medium: premium stylized 3D product illustration, matte ceramic shapes, frosted glass panels, restrained neon edges, crisp and purposeful.
Composition/framing: panoramic 16:7 landscape. Large readable title at the upper left, illustration filling the center and right, generous margins.
Lighting/mood: soft studio illumination with cyan rim lighting, calm and confident.
Color palette: midnight navy, electric cyan, lime highlights, warm coral accent.
Text (verbatim): "REPO STEWARD" and below it "Keep your research repo human-readable."
Constraints: only these two lines of display text; no fake code, no tiny labels, no performance numbers, no third-party logos, no watermark. This is a conceptual illustration, not a software screenshot.
```

## Before / after prompt

```text
Use case: illustration-story
Asset type: supporting wide illustration for the GitHub README of Repo Steward, an AI coding skill for research project organization.
Primary request: Show the transformation from a confusing research repository into a legible, well-organized workspace, in a charming polished isometric diptych.
Scene/backdrop: midnight-blue canvas with two equally weighted adjacent islands connected by a subtle curved cyan trail.
Subject: left island has scattered file cards, duplicate-looking documents, tangled path ribbons, loose experiment folders and a robot research workbench; right island has the same conceptual materials organized into clear stacks and trays with a single visible navigation card and a separate output archive. A small geometric assistant is helping organize the right island.
Style/medium: original premium stylized 3D editorial illustration, matte ceramic and frosted-glass materials, clean outlines, restrained lighting, matching a navy/cyan/lime research-tool brand.
Composition/framing: wide landscape 16:8, readable at GitHub README width, open space around each island, no detailed interface.
Color palette: deep navy, cyan and lime, with coral used sparingly on the disordered left side.
Text (verbatim): "BEFORE" above the left island, "AFTER" above the right island.
Constraints: no other text; no claims of measured speed or token savings; no fake terminal outputs; no recognizable third-party logos; no watermark. Conceptual illustration only.
```
